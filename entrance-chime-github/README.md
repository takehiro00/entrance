# 入店チャイム

スマホの外カメラでエリア内の動きを検知し、チャイムを鳴らすWebアプリです。
AndroidのChromeとiPhoneのSafariを想定しています。インストールやビルド、APIキーは不要です。

## GitHub Pagesで公開する

1. このZIPを展開します。
2. GitHubで公開用リポジトリを作成します。GitHub Freeの場合はPublicを選びます。
3. 「Add file」→「Upload files」から、このフォルダの中身をアップロードしてコミットします。ZIPそのものではなく、index.htmlなどのファイルをアップロードしてください。index.htmlがリポジトリ直下に置かれるようにします。
4. リポジトリの「Settings」→「Pages」を開きます。
5. Sourceを「Deploy from a branch」、Branchを「main」、フォルダを「/(root)」にして「Save」を押します。
6. 公開完了後、Pages画面に表示されるHTTPSのURLをスマホで開きます。

公式手順：https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## 使い方

1. スマホを固定して入口に外カメラを向けます。
2. 「チャイムの音を確認」で音が聞こえることを確認します。端末側の音量も調整してください。
3. 「カメラを起動して開始」を押し、カメラの使用を許可します。
4. 準備が終わったら、検知エリア内を通過して確認します。
5. 必要なら「検知を調整する」で感度・範囲・音量・通知間隔を調整します。

## 動作について

- HTTPSで公開したページを利用してください。ファイルの直接起動では動作しない場合があります。
- 画面を開いたまま使用します。別アプリへ切り替えたり画面をロックしたりすると停止します。戻って再度開始してください。
- 人・物の動きに反応する方式です。人物認識や入退店方向の判別はしません。影や照明の変化、カメラの揺れでも反応する場合があります。
- 映像はブラウザ内で処理し、録画・保存・外部送信しません。マイクは使用しません。
- 両OSの実機でのカメラ・音声の動作確認は未実施です。実際の設置場所で感度と音量を確認してください。

## ファイル

- index.html：画面
- style.css：デザイン
- app.js：カメラ、音声、操作
- detector.mjs：動きの検知
- .nojekyll：GitHub Pagesで静的ファイルをそのまま配信する設定

相対パスを使用しているため、リポジトリ名付きのGitHub Pages URLでも利用できます。
