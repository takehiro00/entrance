# 入店チャイム v5

スマホの外カメラで動きを検知して音を再生するWebアプリです。

## GitHub Pagesへ更新

ZIPを展開し、中身をリポジトリ直下に上書きしてください。soundsフォルダも中の6つのMP3と一緒にアップロードしてください。
Settings → Pages → Deploy from a branch → main → /(root) を選択して公開します。
更新後は https://takehiro00.github.io/entrance/?v=5 を開いてください。
旧chime.wavは使用しません。残っていても動作に影響しません。

## 標準音の抽選確率

| ファイル | 確率 |
|---|---:|
| ko-shun01.mp3 | 2% |
| ko-shun02.mp3 | 2% |
| irassyai01.mp3 | 24% |
| irassyai02.mp3 | 24% |
| havanai.mp3 | 24% |
| temcom.mp3 | 24% |

検知・試聴・開始時の確認音は毎回独立して抽選します。同じ音が続く場合もあり、100回の再生で必ず表の回数になるわけではありません。

## ユーザー設定の音

設定でWAV／MP3を複数選択すると、そのファイルだけを等確率でランダム再生します。1ファイル20MBまで。標準に戻すと上記の6種類と確率に戻ります。再読み込みでも標準に戻ります。選択したファイルは端末内で再生し、外部に送信しません。

## 使い方・制約

AndroidはChrome、iPhoneはSafariでHTTPSの公開URLを開いてください。音を確認し、開始ボタンでカメラを許可します。スマホを固定して画面を開いたまま利用してください。別アプリへ移動すると停止します。
iPhoneの音量は端末の音量ボタンで調整してください。人物や進行方向を判別する方式ではなく、影や揺れにも反応する場合があります。映像は録画・保存・送信しません。
検知停止の回帰テストと抽選の境界・配分を検証しています。スマホ実機での音声出力は未確認です。
